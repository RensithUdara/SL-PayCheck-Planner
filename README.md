# 💼 Sri Lanka Salary Calculator

A clean, fast, and mobile-friendly salary toolkit for Sri Lanka 🇱🇰. This project helps users calculate **EPF, ETF, APIT (PAYE) tax, net take-home pay, salary growth, job-role benchmarks, retirement projections, and extra salary tools** in one simple interface.

🌐 Live demo: https://sl-salary-cal.vercel.app/

---

## ✨ What This App Does

This project is a **static frontend web app** built with **HTML, CSS, and vanilla JavaScript**. It provides easy-to-use salary and retirement calculators for employees in Sri Lanka, with support for both **private sector** and **government sector** scenarios.

### 🔥 Main Highlights
- 📊 Salary calculator for gross pay, deductions, and take-home pay
- 🧾 EPF, ETF, and APIT (PAYE) tax calculations
- 🏛️ Government sector pension reference and official rates page
- 📈 Salary growth projections over multiple years
- 👔 Job role salary benchmarks by industry and experience level
- 🧮 Extra tools like reverse salary calculation, job offer comparison, bonus tax, and loan EMI estimation
- 🌙 Theme toggle with saved preference in the browser
- 📱 Responsive layout optimized for mobile and desktop

---

## 🧭 Pages in This Project

### 1. Home Calculator - `index.html`
The main dashboard for salary calculations.

It includes:
- Gross salary input
- EPF and ETF calculation
- APIT tax calculation
- Net salary and employer cost breakdown
- Salary growth tab
- Job roles benchmark tab
- Shortcut links to official rates and extra tools

### 2. Official Rates - `report.html`
A reference page for Sri Lanka’s current official salary-related rates and rules.

It covers:
- APIT tax table for 2025/2026
- EPF and ETF contribution rates
- Government pension information
- Source references and notes

### 3. More Tools - `manager.html`
A tool hub for additional salary utilities.

It includes:
- Reverse net-to-gross calculator
- Job offer comparison tool
- Bonus / lump-sum APIT calculator
- Loan EMI and affordability calculator

### 4. Retirement Planner - `retirement.html`
A retirement-focused page for long-term planning.

It supports:
- Private sector EPF/ETF projection
- Government sector pension estimate
- Retirement summary suitable for printing or saving as PDF

### 5. Theme Support - `theme.js`
A shared script that handles the light/dark theme toggle and remembers the user’s preference.

## 🏁 How to Run Locally

Because this is a static site, you can run it in several simple ways.

### Option 1: Open directly
1. Download or clone the project.
2. Open `index.html` in your browser.

### Option 2: Use VS Code Live Server
1. Install the **Live Server** extension in VS Code.
2. Open the project folder.
3. Right-click `index.html`.
4. Click **Open with Live Server**.

### Option 3: Deploy as static files
You can host the project on:
- Vercel
- Netlify
- GitHub Pages
- Any static hosting platform

## 📌 Useful Notes

- APIT, EPF, ETF, and pension rules can change over time
- The rates shown in the app are based on the 2025/2026 year of assessment
- Always confirm official values with the **IRD**, your employer, or a qualified accountant before making financial decisions
- Government sector pension rules differ from private sector EPF/ETF rules
